# YANT - Yet Another New Tab
I like Chrome's default new tab/homepage, but hate that it only works if you have Google as your search engine. So I asked Claude to make yet another new tab extension. This is a pixel-close clone of Chrome's default homepage with ~95% visual and functional accuracy that works with **any** search engine and browser. Feel free to contribute!

## Features

- Makes your browser look clean *and* consistent regardless of your search engine
- Changing your search engine changes the header
- Header color is adaptive to the background
- Solid, gradient, or your own image (including GIFs) can be used as a background
- Dark and Light themes
- Color palette to make the new-tab UI match the color of your browser
- Fast access to Google Services
- Can use your Google account pfp instead of the placeholder so it looks more natural

## Installation
I don't have the $5 needed to post it on Chrome Web Store, so this extension comes unpacked. Here is a guide in case you don't know how to install unpacked extensions ^-^
### Step 1:
Download the extension from "Releases" page on GitHub

<img width="1280" height="720" alt="" src="https://github.com/user-attachments/assets/fdc38467-ade5-41c3-8777-ac4f9efb3f07" />
Or just click this button here -> [DOWNLOAD](https://github.com/geezex-xD/YANT/releases/download/1.0.1/YANT1.0.1.zip)
### Step 2:
Unzip it. If you're on Windows 11, just select YANT.zip in the explorer and click "Extract all". If you're on Windows 10, select the archive, then click it with the right mouse button, then click "extract All..."
On MacOS, right-click (or control-click) the .zip file, choose "Open With", then select "Archive Utility".
On Linux, use File Roller or another archiver.
Remember where you extracted the archive.
<img width="1280" height="720" alt="" src="https://github.com/user-attachments/assets/b4fb7c72-07a2-41a1-aabb-2e19977aed8d" />
### Step 3:
Open your Google Chrome or another Chromium-based (Edge, Brave, Vivaldi, Opera, Yandex, Arc) browser and type "chrome://extensions/" into the address bar.
Here, enable the "Developer mode", using the toggle in the upper right corner.
<img width="1280" height="720" alt="" src="https://github.com/user-attachments/assets/feb3eb10-d3e7-40b0-8f50-23c68fb6960a" />
### Step 4:
Select "Load unpacked" in the upper left corner. A file manager window will pop up. Navigate to the extracted folder. Then click "Select folder"
<img width="1280" height="720" alt="" src="https://github.com/user-attachments/assets/2bb32318-0c40-40b4-9fca-573b23f3fcce" />
<img width="1280" height="720" alt="" src="https://github.com/user-attachments/assets/0d37f2a1-dbbf-419f-9ff1-bba684b67e61" />
Never delete the folder if you don't want the extension to stop working. The original .zip file may be deleted.
### Step 5: You are irresistible <3!
